## Policy answers, checked

- **Entry points and authorisation.** `POST /auth/register` and `POST /auth/login` are the two
  unauthenticated data routes, by design: nobody has a token before they exist. `GET /auth/me`
  requires a valid bearer token. The check is `get_current_user`, a dependency every later router
  declares; a missing, malformed, expired, tampered or unknown-user token is 401 with
  `WWW-Authenticate: Bearer`. Default is deny: the dependency raises before any data is read.
- **Credentials.** Passwords are hashed with Argon2id through `pwdlib`'s recommended hasher
  (HD's password-hashing decision) and never stored or logged in clear. Login returns the same 401
  body for an unknown email and a wrong password, and verifies against a dummy hash when the email is
  unknown so the two cases take the same time.
- **Tokens.** HS256 JWTs signed with `JWT_SECRET`, carrying `sub` (the user id), `iat` and `exp`.
  Decoding pins the algorithm, requires all three claims, and checks expiry on the server. Lifetime
  is `JWT_EXPIRE_MINUTES`, default 60, a product decision recorded in the spec. No refresh token.
- **Secrets.** `JWT_SECRET` arrives from the environment through `Settings` as a `SecretStr`, so it
  never appears in a repr or a log. The app refuses the `.env.example` placeholder and any value
  under 32 characters, which is PyJWT's own minimum for HS256. The test suite sets its own throwaway
  secret, so no real secret is needed to run tests.
- **Personal data.** The email is the only personal data. It is stored lower-cased in `users`, is
  returned only to its own user (`/auth/me` and the register response), and is never logged: auth
  log lines carry a reason and, where known, the user id.
- **Input.** `EmailStr` validates the address; the schema strips and lower-cases it. Passwords are
  8 to 128 characters on register. Everything else is FastAPI typing.
- **Data access.** `register` inserts one row and relies on the unique constraint for the race:
  an `IntegrityError` becomes 409. `login` and `get_current_user` are one indexed lookup each
  (`uq_users_email`, primary key).
- **Dependency failure.** Postgres only; the 503 handler from PR 2 covers it. No outbound calls.
- **Observability.** Registration (`user_id`), failed logins (no identifier) and failed
  authentication (`reason`) emit a line. The per-request log line gains `user_id` when the request
  was authenticated, so every later endpoint's traffic is attributable.
- **Testing.** Unit: hashing and token helpers, settings validation, the schemas, all without a
  database. Integration: every `/auth` path, success and failure, through the FastAPI test client
  with `get_db` overridden by the rolled-back session from PR 2.

```python
"""Application settings, read from the environment.

Values come from the process environment first, then from the repository-root ``.env`` file when
it exists. Inside Docker there is no ``.env``: Compose injects the variables.
"""

from functools import lru_cache
from pathlib import Path
from typing import Annotated

from fastapi import Depends
from pydantic import SecretStr, field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict

_ENV_FILE = Path(__file__).resolve().parents[2] / ".env"

JWT_SECRET_PLACEHOLDER = "change-me-generate-a-real-secret-see-README"
MIN_JWT_SECRET_LENGTH = 32


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=_ENV_FILE, env_file_encoding="utf-8", extra="ignore")

    database_url: str
    cors_origins: str = "http://localhost:3000"
    jwt_secret: SecretStr
    jwt_expire_minutes: int = 60

    @property
    def cors_origin_list(self) -> list[str]:
        """``CORS_ORIGINS`` as a list: comma-separated in the environment, blanks dropped."""
        return [origin.strip() for origin in self.cors_origins.split(",") if origin.strip()]

    @field_validator("jwt_secret")
    @classmethod
    def _jwt_secret_is_real(cls, value: SecretStr) -> SecretStr:
        """Refuse the example placeholder and anything shorter than HS256's recommended key.

        A ``SecretStr`` keeps the value out of reprs and logs; this is the one place it is read.
        """
        secret = value.get_secret_value()
        if secret == JWT_SECRET_PLACEHOLDER or len(secret) < MIN_JWT_SECRET_LENGTH:
            raise ValueError(
                f"JWT_SECRET must be at least {MIN_JWT_SECRET_LENGTH} characters and not the "
                "placeholder from .env.example. Generate one with: "
                'python -c "import secrets; print(secrets.token_urlsafe(48))"'
            )
        return value


@lru_cache
def get_settings() -> Settings:
    """One ``Settings`` per process. Tests clear the cache after changing the environment."""
    return Settings()


SettingsDep = Annotated[Settings, Depends(get_settings)]
```

- [ ] **Step 3: Password hashing and tokens**

`backend/app/security.py`:

```python
"""Password hashing and access tokens.

Passwords are hashed with Argon2id, the library's recommended hasher. Access tokens are HS256
JSON Web Tokens carrying the user id as ``sub``, plus ``iat`` and ``exp``; decoding pins the
algorithm, requires all three claims and checks expiry. Nothing here touches the database or the
request: ``app/auth.py`` turns a token into a user.
"""

from datetime import UTC, datetime, timedelta

import jwt
from pwdlib import PasswordHash

from app.config import Settings

ALGORITHM = "HS256"

_password_hash = PasswordHash.recommended()


class TokenError(Exception):
    """The token is missing, malformed, expired, tampered with or signed with another key."""


def hash_password(password: str) -> str:
    return _password_hash.hash(password)


def verify_password(password: str, password_hash: str) -> bool:
    return _password_hash.verify(password, password_hash)


def create_access_token(user_id: int, settings: Settings, now: datetime | None = None) -> str:
    """A signed token for ``user_id`` that expires ``settings.jwt_expire_minutes`` after ``now``."""
    issued_at = now or datetime.now(UTC)
    claims = {
        "sub": str(user_id),
        "iat": issued_at,
        "exp": issued_at + timedelta(minutes=settings.jwt_expire_minutes),
    }
    return jwt.encode(claims, settings.jwt_secret.get_secret_value(), algorithm=ALGORITHM)


def decode_access_token(token: str, settings: Settings) -> int:
    """The user id a valid token names. Raises ``TokenError`` for anything else."""
    try:
        claims = jwt.decode(
            token,
            settings.jwt_secret.get_secret_value(),
            algorithms=[ALGORITHM],
            options={"require": ["sub", "iat", "exp"]},
        )
    except jwt.InvalidTokenError as exc:
        raise TokenError(str(exc)) from exc
    subject = claims.get("sub")
    if not isinstance(subject, str) or not subject.isdigit():
        raise TokenError("subject is not a user id")
    return int(subject)
```

```python
"""Request and response schemas for sign-in.

Request and response classes are separate: a response never carries the password or its hash.
"""

from datetime import datetime
from typing import Literal

from pydantic import BaseModel, ConfigDict, EmailStr, Field, field_validator

PASSWORD_MIN_LENGTH = 8
PASSWORD_MAX_LENGTH = 128


def _normalise_email(value: str) -> str:
    """One spelling per address: trimmed and lower-cased, so the unique constraint sees repeats."""
    return value.strip().lower()


class UserRegister(BaseModel):
    email: EmailStr
    password: str = Field(min_length=PASSWORD_MIN_LENGTH, max_length=PASSWORD_MAX_LENGTH)

    @field_validator("email", mode="after")
    @classmethod
    def _lower_email(cls, value: str) -> str:
        return _normalise_email(value)


class UserLogin(BaseModel):
    email: EmailStr
    password: str = Field(min_length=1, max_length=PASSWORD_MAX_LENGTH)

    @field_validator("email", mode="after")
    @classmethod
    def _lower_email(cls, value: str) -> str:
        return _normalise_email(value)


class UserRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    email: str
    created_at: datetime


class Token(BaseModel):
    access_token: str
    token_type: Literal["bearer"] = "bearer"
```

- [ ] **Step 2: The current-user dependency**

`backend/app/auth.py`:

```python
"""Who is making this request.

``get_current_user`` is the one place a bearer token becomes a user. Every router that needs a
signed-in user declares ``CurrentUserDep``; nothing else reads the token (ADR 0002 keeps auth
behind this seam so another identity provider can replace it later).

Every failure is 401 with ``WWW-Authenticate: Bearer`` and the same body, and is logged with a
reason but never with the token or an email.
"""

import logging
from typing import Annotated

from fastapi import Depends, HTTPException, Request, status
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer

from app.config import SettingsDep
from app.database import SessionDep
from app.models import User
from app.security import TokenError, decode_access_token

logger = logging.getLogger("taskmind.auth")

_bearer = HTTPBearer(auto_error=False)
BearerDep = Annotated[HTTPAuthorizationCredentials | None, Depends(_bearer)]


def unauthorised(detail: str = "Not authenticated") -> HTTPException:
    return HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail=detail,
        headers={"WWW-Authenticate": "Bearer"},
    )


def get_current_user(
    request: Request, credentials: BearerDep, db: SessionDep, settings: SettingsDep
) -> User:
    if credentials is None:
        logger.warning("authentication failed", extra={"fields": {"reason": "no token"}})
        raise unauthorised()
    try:
        user_id = decode_access_token(credentials.credentials, settings)
    except TokenError as exc:
        logger.warning(
            "authentication failed",
            extra={"fields": {"reason": "invalid token", "detail": str(exc)}},
        )
        raise unauthorised() from exc
    user = db.get(User, user_id)
    if user is None:
        logger.warning(
            "authentication failed",
            extra={"fields": {"reason": "unknown user", "user_id": user_id}},
        )
        raise unauthorised()
    request.state.user_id = user.id
    return user


CurrentUserDep = Annotated[User, Depends(get_current_user)]
```

`HTTPBearer(auto_error=False)` returns `None` for a missing or non-bearer header instead of its
own 403, so every failure goes through `unauthorised()` and gets the same 401. It also puts the
"Authorize" button on `/docs`.

- [ ] **Step 3: The router**

`backend/app/routers/auth.py`:

```python
"""Register, log in, and who am I."""

import logging

from fastapi import APIRouter, HTTPException, status
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError

from app.auth import CurrentUserDep, unauthorised
from app.config import SettingsDep
from app.database import SessionDep
from app.models import User
from app.schemas.user import Token, UserLogin, UserRead, UserRegister
from app.security import create_access_token, hash_password, verify_password

logger = logging.getLogger("taskmind.auth")

router = APIRouter(prefix="/auth", tags=["auth"])

# Verified against when the email is unknown, so a login attempt takes the same time whether or
# not the address exists. Computed once at import.
_DUMMY_HASH = hash_password("not-a-real-password")


@router.post("/register", status_code=status.HTTP_201_CREATED)
def register(body: UserRegister, db: SessionDep) -> UserRead:
    user = User(email=body.email, password_hash=hash_password(body.password))
    db.add(user)
    try:
        db.commit()
    except IntegrityError:
        # The unique constraint on email is the race-safe check; a second registration of the
        # same address lands here whatever the timing.
        db.rollback()
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT, detail="Email already registered"
        ) from None
    db.refresh(user)
    logger.info("user registered", extra={"fields": {"user_id": user.id}})
    return UserRead.model_validate(user)


@router.post("/login")
def login(body: UserLogin, db: SessionDep, settings: SettingsDep) -> Token:
    user = db.scalar(select(User).where(User.email == body.email))
    password_ok = verify_password(body.password, user.password_hash if user else _DUMMY_HASH)
    if user is None or not password_ok:
        logger.warning("login failed", extra={"fields": {"reason": "bad credentials"}})
        raise unauthorised("Incorrect email or password")
    return Token(access_token=create_access_token(user.id, settings))


@router.get("/me")
def me(user: CurrentUserDep) -> UserRead:
    return UserRead.model_validate(user)
```
